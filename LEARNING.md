# Git Learning Notes

## Các lệnh Git đã học

- git clone: Tải repository về máy
- git add: Đưa thay đổi vào staging
- git commit: Lưu thay đổi vào lịch sử Git
- git push: Đẩy commit lên GitHub
- git pull: Lấy và tích hợp thay đổi từ remote
- git branch: Xem danh sách nhánh
- git switch: Chuyển nhánh
